# lucx-ui.js

The page side of the panel bridge for plugins that show their own pages. MIT-licensed, like the examples: copy
`lucx-ui.js` (and `lucx-ui.d.ts` if you use TypeScript) into your plugin's `ui/` directory.
`examples/ui-hello` is a page-only plugin; `examples/hello-plugin` has a page that calls its own backend.
See *Interface pages* in `docs/plugin-development.md` for what a page may and may not do.
